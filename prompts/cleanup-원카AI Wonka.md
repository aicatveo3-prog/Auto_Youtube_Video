이 텍스트를 아래 지침에 따라 **영상 없이도 따라 할 수 있는 실습 가이드**로 정리해줘.

## 0. 이 프롬프트를 쓰는 이유
원카AI 채널은 AI 도구를 활용한 실전 튜토리얼을 다룬다.
화면을 가리키며 "여기 보시면~" 식으로 설명하기 때문에,
영상 없이 텍스트만 읽으면 핵심 단계를 놓치기 쉽다.
따라서 이 프롬프트는 **영상을 다시 보지 않아도 글만 보고
따라 할 수 있는 구조화된 가이드**를 만드는 것에 초점을 둔다.

## 1. 텍스트 정제 규칙
- 구어체(~거든요, ~잖아요, 자 여기 보시면, 어, 뭐 등)를 자연스러운 문어체로 전환
- "자,", "어,", "근데", "보시면", "하시면 되고요" 같은 라이브 진행 멘트는 과감히 삭제
- 같은 내용의 반복은 가장 명확한 표현 하나만 남기고 제거
- [음악], 말 더듬, 문장 꼬임 등 노이즈 제거
- 오탈자·음성인식 오류는 문맥에 맞게 교정
  (예: "재미나이" → "제미나이", "미드전이" → "미드저니", "수호" → "Suno")
- **광고·협찬·구독 요청 파트는 통째로 제거** (무료 크레딧 홍보, 채널 구독 유도 등)

## 2. 구조화 규칙 — "워크플로우 → 단계별 가이드"
- 글 맨 앞에 **완성 결과물이 무엇인지** 한두 문장으로 요약
- 그 아래에 **전체 워크플로우 맵**을 넣기:
  사용하는 도구와 순서를 한눈에 보여주는 흐름도
  예: `제미나이(시나리오) → 미드저니(이미지) → 구글 플로우(영상) → 프리미어 프로(편집)`
- 본문은 **단계별로 섹션** 나누기:
  `## 1단계: 시나리오 기획 (제미나이)` 처럼 단계 번호 + 목적 + (사용 도구)
- 하위 논점은 ### 소제목 사용
- 단계 안에서 세부 조작이 많으면 **번호 리스트(1. 2. 3.)**로 정리
- 글 맨 끝에 🧠 이모지와 함께 핵심 한 줄 요약 넣기

## 3. 서술 스타일 — "따라 하기 가이드"
- **클릭 경로는 화살표(→)로 시각화**:
  예: `좌측 패널 → 도구 → 스토리보드 스튜디오`
  예: `프롬프트 창 하단 → 이미지/동영상 설정 → 동영상 → 옴니 1.1 플래시`
- **AI에 입력하는 프롬프트 원문은 반드시 코드 블록(```)으로 보존**
  — 독자가 복사해서 바로 쓸 수 있어야 한다
  — 다만 프롬프트가 너무 길면 핵심 구조만 발췌하고 "[전체 프롬프트는 원본 참고]"로 표기
- **꿀팁·주의사항은 > 인용 블록으로 분리**하여 눈에 띄게
  예: > 💡 **꿀팁**: 코드 블록 내에 담아달라고 요청하면 제미나이가 이미지 대신 텍스트로 준다.
  예: > ⚠️ **주의**: 스토리보드 도구에서 완료 버튼을 누르면 작업 화면으로 돌아갈 수 없다.
- **도구별 설정값은 표로 정리**:
  예: | 항목 | 설정값 |
      | 모델 | 옴니 1.1 플래시 |
      | 해상도 | 720p |
      | 길이 | 10초 |
- 딱딱한 매뉴얼 느낌이 아니라, 옆에서 같이 해보면서 알려주는 편한 톤
- 전문 용어가 나올 때마다 괄호나 한 문장으로 풀어설명
  예: "멀티샷(하나의 영상 안에 여러 장면을 한꺼번에 생성하는 방식)"
  예: "페어론(부부가 각각 별도로 대출을 받아 합산하는 방식)" → 이건 원카AI에는 안 나오지만 형식 예시

## 4. 콘텐츠 규칙
- 원본에 없는 내용은 절대 추가하지 않기
- **단, 단계 간 연결 문장은 살려도 됨**
  (예: "시나리오가 준비됐으니 이제 이것을 이미지로 만들 차례다" 식의 전환)
- 원본에서 언급한 도구명, 모델명, 버전, 가격, 크레딧 수치는 정확히 보존
- 모호한 부분도 원본 그대로 두기 (임의로 확대해석 금지)
- 영상 내에서 보여준 결과물 묘사는 간결하게 유지
  (텍스트로는 영상을 재현할 수 없으므로, "다음과 같은 결과물이 나온다" 정도로)

## 5. 비용·도구 요약
- 글 끝에 **사용 도구 및 비용 요약표**를 넣기:
  | 도구 | 용도 | 비용 |
  | --- | --- | --- |
  | 제미나이 | 시나리오 기획 | 무료 (구글 계정) |
  | 미드저니 | 이미지 생성 | 월 $10 (200장) |
  | ... | ... | ... |
  — 원본에서 언급한 비용 정보가 있으면 반영, 없으면 생략

## 6. 분량
- 원본의 모든 실습 단계를 빠뜨리지 않되, 노이즈·광고 제거 + 구조화로 정리
- **분량 제한 없음** — 따라 하기에 필요한 정보는 전부 담기
- 줄이는 것보다 **"글만 보고 따라 할 수 있는 것"**이 최우선
