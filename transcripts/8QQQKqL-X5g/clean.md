## 3. 반복 수정 과정 — 딸깍 한 번으로 안 된다

### 수정 요청들

표지 레이아웃 가운데 정렬, 의미 없는 도형과 텍스트 삭제, 프로필·인덱스 글자 크기 축소, 레퍼런스 기반 리디자인, 배경색 변경, 폰트 믹스 매치, 아이콘·픽토그램 삭제, 기울기 다르게 등 여러 번 수정을 요청했다.

### 겪은 문제들

- **도형을 50% 빼 달라고 했는데 80~90% 빠졌다.** AI가 정확한 비율을 이해하지 못한다.
- **레퍼런스를 첨부해서 리디자인을 요청했는데 너무 다른 결과**가 나왔다.
- 여백을 늘려 달라고 하면 너무 많이 만들고, 줄이면 너무 적다. **정확한 퍼센트를 지정해야 하는** 것 같다.
- **열 번 가까이 수정하면서 오타가 점점 늘어났다.** 한글 인식률이 반복 수정할수록 떨어지는 느낌이 있다.
- **자간(글자 사이 간격)이 너무 넓은** 것이 여러 번 나타났다. 실무진이 보면 바로 "기본기 안 됐네" 하고 느낀다.

> 그냥 진짜 딸깍만으로 되지 않는다. 하나의 결과물을 만들기 위해서는 계속 요청해야 하는데, **뭐가 괜찮고 뭐가 잘못됐는지에 대한 기본적인 이론과 개념을 알아야** 요청을 할 수 있다.

## 4. 존코바가 직접 리디자인

AI의 결과물에 만족하지 못했기 때문에 직접 리디자인을 했다.

### 표지 수정 포인트
- 요청했던 기울기에 맞게 조정
- 여러 폰트를 믹스 매치 (세리프 + 산세리프)
- 인터페이스 요소는 과하지 않게
- 포인트 컬러 + 배경에 어두운 그라데이션을 활용해 **글자에 집중**되게
- 단색만으로는 미완성 느낌이 나기 때문에

### 프로필 수정 포인트
- 흑백 사진으로 변환 (배경이 강렬하기 때문에)
- 포인트 컬러는 살리되, **중요하지 않은 텍스트는 색을 연하게** 해서 두 번째로 읽히도록
- 여백을 만들어 얼굴과 글자가 잘 보이도록
- 글자 크기를 줄여서 시선의 우선순위를 잡아줌

### AI만으로는 부족한 것
- 초안을 바로 쓰기에는 부족하다. **디자인 이론, 경험, 디렉팅 지식**이 있어야 수정 요청을 제대로 할 수 있다.
- AI가 "해 줘" 하면 나오는 것은 사실이지만, **그걸 디렉팅할 수 있는 지식이 없으면 예쁘기만 한 결과물**에서 끝난다.
