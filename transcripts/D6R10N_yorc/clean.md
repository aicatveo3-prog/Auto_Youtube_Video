## 0단계: AI 에이전트란 무엇인가

일반적인 AI(챗GPT, 제미나이, 클로드 등)는 **물어보면 대답해 주는** 도구다. 반면 AI 에이전트는 **시키면 알아서 하는** 존재다.

- 지정한 파일을 알아서 열어보고
- 추가로 필요한 정보는 검색해서 찾아오고
- 그것을 조합해서 PPT를 만들고, 엑셀을 만들고
- 시간이 되면 알림까지 보내준다

그 사이 사용자는 다른 일을 하고 있으면 된다. 도구가 아니라 사실상 **비서**에 가깝다.

> 💡 팀 페리스의 《나는 4시간만 일한다》에서 강조하는 "아웃소싱"과 같은 개념인데, 인도 원격 비서를 고용할 필요 없이 **노트북과 AI 에이전트만 있으면 된다**.

## 1단계: 마누스 설치 및 환경 세팅

### 마누스를 선택한 이유

다른 AI 에이전트는 설치할 것이 많고 이것저것 설정하다 지치기 쉽다. 마누스는 **앱만 받고 연결하면 끝**이라서 입문하기에 가장 적합하다.

### 설치 방법

1. 구글에서 `Manus` 검색 → 최상단 결과 클릭
2. 웹에서도 사용 가능하지만, **데스크톱 앱 다운로드**를 권장
3. 프로필 옆 컴퓨터/모바일 아이콘 → `데스크톱 앱` 클릭 → 다운로드 → 설치
4. 구글 계정으로 로그인

### 로컬 폴더 연결 (핵심 세팅)

마누스가 내 컴퓨터의 파일을 직접 읽고 활용할 수 있도록 연결하는 과정이다.

1. 프롬프트 창 하단 → `마누스 데스크톱` 클릭
2. `로컬 폴더 추가` 클릭
3. 작업용 폴더를 하나 만들어서 (예: "마누스" 또는 "나만의 저장소") 선택 → 열기
4. 이 폴더 안에 마누스가 참조할 자료(유튜브 대본, 이미지, 영상 등)를 넣어두면 된다

> 💡 폴더 이름은 아무거나 상관없다. 핵심은 마누스가 **이 폴더 안의 파일을 자유롭게 열어보고 정리할 수 있게** 권한을 열어주는 것이다.

### Gmail 연동

1. 프롬프트 창 하단 → 좌측 패널 → `플러그인` 클릭
2. `커넥터` 항목에서 검색창에 `Gmail` 입력
3. 플러스 버튼 → 구글 계정 로그인 → 연결 완료

> 💡 **모바일 앱도 설치**해 두면, 컴퓨터에서 작업한 것을 이동 중에 앱으로 이어서 수정할 수 있다. 같은 대화창이 컴퓨터와 모바일에서 공유된다.

## 2단계: PPT 제작 — 재료 넣기

PPT 제작은 세 단계로 진행한다: **재료 투입 → 스타일 확정(샘플 1장) → 전체 완성**.

### 기업용 PPT의 현실

대기업 기업분석 담당으로 30년간 근무한 전문가의 조언에 따르면:

- 기업 PPT에서 가장 중요한 것은 디자인이나 전달력이 아니라 **"위에 계신 분 마음"**
- 회사마다 형식이 완전히 다름 — 세로 배포도 있고, 워드로 작성하는 경우도 있음
- 임원 회의용이면 디자인보다 **수익 이야기**가 핵심
- 대부분의 기업 PPT는 **출력을 고려**해야 함 — 흑백 인쇄가 많으므로 화려한 배경을 깔지 않는 것이 센스

### 목적 파악 (재료 넣기)

마누스에 다음과 같은 프롬프트를 입력한다:

```
기업 담당자님과 이메일을 통해 주고받은 내용과 내가 생각한 부분은 다음과 같아.
내가 준비해야 할 것을 정리해 줘.
```

마누스가 어떤 곳에서 어떤 목적으로 강연을 요청했는지 파악하고, 준비해야 할 사항까지 정리해 준다. 이렇게 하면 마누스도 **PPT의 목적을 인지한 채로** 제작할 수 있다.

## 3단계: PPT 제작 — 스타일 확정 (샘플 1장)

### 디자인 참조 방법

- 회사 내부에 기존 PPT 형식이 있으면 → 그 파일을 첨부
- 아이디어가 필요하면 → 핀터레스트에서 `PPT 템플릿` 검색해서 참고

마누스에 다음과 같이 요청한다:

```
커리큘럼 세부 안내서를 기업 PPT 형식으로 제작하려고 해.
형식은 내가 첨부한 PPT 형식으로 제작해 줘.
일단 본문 한 페이지만 만들어 줘.
```

참조할 자료도 함께 지정한다:

```
다음 사항을 참조해 줘:
- [연결된 폴더] 내 유튜브 대본을 확인할 것
- PPT 관련 영상과 쇼츠 관련 내용에 집중할 것
- 썸네일과 영상 파일도 적절히 PPT 내에 반영할 것
- PPTX 형태로 만들 것
- 흑백으로 인쇄해도 글씨가 잘 보이게 할 것
```

> ⚠️ **왜 한 페이지만 먼저 만드는가**: PPT가 20장인데 다 만든 뒤에 "이런 스타일 아니었는데" 하면 시간과 크레딧을 두 배로 날린다. **여러 슬라이드를 만드는 작업에서는 반드시 샘플 1장을 먼저 확인**하는 것을 추천한다.

### 피드백으로 다듬기

샘플이 나오면 피드백을 준다:

```
가독성이 떨어지는 것 같다.
너무 많은 내용을 한 슬라이드에 담을 필요 없이 다음 슬라이드로 넘겨서 활용해도 된다.
```

이런 식으로 한 슬라이드를 확정한 뒤 전체로 넘어간다.

## 4단계: PPT 제작 — 전체 슬라이드 완성

샘플이 확정되면 나머지를 요청한다:

```
이 슬라이드를 기준으로 나머지도 다 만들어 줘.
색과 폰트, 상단 목차는 이것대로 유지해 줘.
만들면서 필요한 이미지가 있으면 미리 알려 줘.
```

마누스가 연결된 폴더의 파일(유튜브 대본, 영상, 이미지)을 하나씩 분석한 뒤, 참조한 PPT의 색상과 형태를 바탕으로 전체 슬라이드를 제작한다.

> 💡 마누스에게 **"필요한 이미지가 있으면 미리 알려 줘"**라고 해두면, 직접 이미지를 제공할 수 있어서 결과물 품질이 올라간다. 진짜 직원과 대화한다고 생각하면 편하다.

## 5단계: 스킬 저장 — 다음에 또 쓰기

지금까지의 PPT 제작 과정을 **하나의 재사용 가능한 가이드(스킬)**로 저장할 수 있다. 다음에 비슷한 PPT를 만들 때 이 스킬만 불러오면 처음부터 다시 설명할 필요가 없다.

### 스킬 만드는 방법

1. 프롬프트 창 → 플러스(+) 버튼 → `스킬 사용` 클릭
2. 다양한 스킬 목록 중 `스킬 크리에이터` 클릭
3. 다음과 같이 입력:

```
지금까지 활용한 PPT 제작 방식을 하나의 스킬로 저장해 줘.
```

4. 생성된 스킬을 `내 스킬에 추가` 버튼으로 저장

이후에는 이렇게 요청하면 된다:

```
[PPT 제작 스킬]을 이용해서 다음 PPT를 제작해 줘.
```

## 6단계: Gmail 연동 — 메일 확인·회신·알림

### 회신 초안 작성

```
해당 내용을 첨부하면서 회신을 하려고 해. 회신 메일 초안을 작성해 줘.
```

마누스가 초안을 작성하면 **임시보관함에 넣어 달라**고 요청한다. 그러면 Gmail 임시보관함에서 직접 확인하고, 문제없으면 발송 버튼을 누르면 된다.

> ⚠️ **반드시 검수 후 발송할 것**. 마누스가 작성한 초안을 그대로 보내지 말고, Gmail에서 한 번 훑어보고 곤란해질 내용이 없는지 확인한 뒤 전송한다.

### 예약 알림 설정

메일함을 계속 들여다볼 수 없으니, 마누스에게 자동 확인을 맡긴다:

```
제안서 PPT 관련 회신이 왔는지 매일 오전 10시에 확인하고 알려 줘.
```

마누스가 두 가지 방법을 제시한다:
- **간편 예약 브리프**: 설정한 시간에 메일을 확인하고 요약해서 알림을 보내줌
- **별도 자동화 구축**: 더 정교한 자동화 (대부분의 경우 간편 예약으로 충분)

간편 예약을 선택하면, 시간에 맞춰 모바일 앱으로도 알림이 온다.

## 7단계: HTML 발표 자료 변환 (보너스)

해외에서는 발표 자료를 PPTX 대신 HTML 형식으로 만드는 경우가 많다. 마누스를 활용하면 같은 내용을 반응형 HTML로 변환할 수 있다.

```
이제 제작한 커리큘럼 세부 안내서를 같은 내용으로 발표용 HTML 버전으로 하나 만들어 줘.
- 마우스에 반응하는 모션을 넣어서 발표할 때 지루하지 않게 할 것
- 화면 비율은 기존 PPT와 동일하게 유지
- 기존 PPTX는 그대로 두고 별도 파일로 HTML을 만들 것
```

결과물은 겉보기에는 PPT를 그대로 옮겨온 것 같지만, 마우스를 가져다 대면 **반응형 모션**이 작동한다. 메뉴 설명 시 해당 부분에 집중할 수 있도록 모션이 들어가고, 자동 재생 타이머나 발표자 메모 패널도 만들 수 있으며, 영상 링크도 직접 연결할 수 있다.

> ⚠️ **HTML은 반드시 검수할 것**. PPTX에서 HTML로 변환하면 텍스트가 도형 밖으로 삐져나오거나 요소가 겹치는 현상이 발생할 수 있다. 확인 후 수정 요청을 해서 조정해야 한다.

## 사용 도구 및 비용 요약

| 도구 | 용도 | 비용 |
|------|------|------|
| 마누스(Manus) | PPT 제작, 메일 관리, HTML 변환 전체 | 무료 크레딧 제공 (이후 유료) |

🧠 AI 에이전트의 핵심은 "물어보면 답해주는 도구"가 아니라 **"시키면 알아서 하는 비서"**라는 것이며, PPT 제작 → 메일 관리 → 알림 설정 → HTML 변환까지 하나의 대화창에서 전부 처리할 수 있다는 점이 마누스의 가장 큰 장점이다.
