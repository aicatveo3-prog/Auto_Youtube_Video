시작 이미지와 끝 이미지를 던져주면 그 사이를 알아서 채워주는 기능이다. 이전 옴니 모델에서는 끝 프레임 설정이 반영되지 않았는데, 이제 **첫 프레임과 끝 프레임 모두 직접 설정**할 수 있게 됐다. 오늘 영상에서 핵심적으로 사용할 기능이다.

## 1단계: 대본 작성 + 팩트 체크 (제미나이)

### 팩트 체크 요청

대본을 먼저 작성한 뒤(제미나이나 챗GPT, 클로드와 대화하면서 만들 수 있다), 다음과 같이 입력한다:

```
첨부한 대본을 바탕으로 역사 스토리텔링 영상을 만들 거야.
```

## 2단계: 장면 분류 + 구도 설정 (제미나이)

### 장면 분류

팩트 체크가 끝나면 이어서 다음을 입력한다:

```
이대로 갈 거야.
이제 각 대사 부분을 설명해 줄 그림을 미드저니로 뽑을 거야.
대사 한두 문장당 하나의 그림을 구성할 거야.
그림체는 붓으로 그린 느낌으로.
각 프롬프트를 제시해 줘.
```

여기서 핵심 포인트 세 가지:

1. **어떤 모델로 뽑을지 명시**한다 (미드저니). 이렇게 하면 해당 도구에 최적화된 프롬프트를 얻을 수 있다.
2. **대사 한두 문장당 하나의 그림**으로 설정한다. 일반적으로 나레이션 음성과 장면이 얼추 맞게 떨어지기 때문이다. 쉽게 말해 **편집할 때 수고를 크게 줄여준다**.
3. 바로 이미지를 뽑지 않고, **먼저 장면을 표로 분류**해서 내 눈으로 확인한다.

제미나이가 표 형태로 결과를 정리해 준다. 대본 구간별로 어떤 이미지가 보여야 하는지가 명확하게 세팅된다. 이 영상의 경우 **총 12개 장면**으로 정리됐다.

### 구도 다양화 — 시각적 리듬 만들기

> 💡 **꿀팁**: 잘되는 역사 채널을 분석해 보면 각 장면 간 **구도를 다르게** 해서 역동적으로 보이게 만든다. 계속 멀리서만 보다가 갑자기 얼굴로 확 줌인하면 집중이 되는 것처럼, 구도의 변화가 **시청 지속 시간**에 영향을 준다.

이어서 다음을 입력한다:

```
여기서는 넓은 와이드 구도와 클로즈업 구도를 사용할 거야.
한 가지만 쓰지 말고 적절히 섞어 줘.
구도를 옆에 표기해 줘.
```

결과를 보고 와이드가 너무 많으면:

```
너무 와이드만 있는 것 같다. 적절히 다른 구도도 넣어 줘.
```

제미나이가 익스트림 와이드 샷, 미디엄 팔로잉 샷, 오버 더 숄더 샷 같은 다양한 구도를 반영해 준다.

> 💡 쇼츠(숏폼)는 구도를 다양하게 할 필요가 적지만, **장시간 집중이 필요한 롱폼에서는 구도 하나만으로도 시청 지속 시간에 차이**가 난다.

## 3단계: 이미지 생성 (미드저니)

### 프롬프트 추출

스타일을 지정해서 미드저니용 프롬프트를 요청한다:

```
미드저니용 프롬프트로 설정해 줘.
스타일: 붓으로 그린 느낌. 색은 채도 낮고 차갑게.
뒤에 파라미터는 --ar 16:9만 넣어 줘.
코드 블록 내에 프롬프트를 넣어 줘.
```

> 💡 **꿀팁 — 코드 블록 요청**: 제미나이는 가끔 프롬프트를 달라고 했는데 텍스트 대신 이미지를 만들어 버리는 고질병이 있다. **"코드 블록 내에 담아 줘"**라고 요청하면 복사 가능한 텍스트 형태로 받을 수 있고, 우측에 코드 복사 버튼까지 나온다. 이 팁 하나만 알아가도 의미가 있다.

**모든 프롬프트를 한꺼번에 뽑을 필요 없다.** 첫 번째 이미지가 잘 나왔으면 나머지 프롬프트에 그 스타일을 그대로 적용해 달라고 하면 된다.

### 조명을 두 가지로 나누는 기법

> 💡 **꿀팁**: 장면별로 **빛을 두 가지 중 선택**해서 번갈아 쓴다.
> - 첫 번째: 그림자가 거의 없는 빛
> - 두 번째: 해가 들어와서 황금빛이 나는 빛
>
> 정석적으로는 일관된 톤을 전체에 적용하는 것이 맞다. 영화도 그렇게 한다. 하지만 **유튜브 콘텐츠**는 화풍이 이미 통일돼 있는 상태에서 색 온도까지 통일되면 지루해질 수 있다. 각 장면에 다이나믹한 변화를 주면 이목을 더 끌 수 있다.

### 미드저니에서 이미지 생성

1. 구글에서 `Midjourney` 검색 → 상단 결과 클릭 → 구글 계정으로 로그인
2. 상단 프롬프트 창에 복사해 온 프롬프트를 붙여넣기 → 생성
3. 마음에 드는 이미지 채택

### 왜 미드저니인가 (플로우 내장 나노바나 대비)

구글 플로우 안에서도 나노바나로 무료 이미지를 뽑을 수 있지만, **미드저니의 이미지 품질이 압도적으로 높다**. 영상 모델은 결국 입력한 이미지를 움직이게 만드는 것이기 때문에, **출발점(이미지)이 좋으면 결과도 좋고, 출발점이 별로면 아무리 좋은 모델을 써도 한계가 있다**.

## 4단계: 영상화 프롬프트 생성 (제미나이)

이미지가 준비됐으면 영상화 프롬프트를 만든다. 제미나이에 첫 번째 장면 이미지와 두 번째 장면 이미지를 첨부한 뒤:

```
이 첫 번째 이미지를 시작 프레임으로 하고
두 번째 이미지를 끝 프레임으로 하여
옴니 1.1 플래시 모델을 이용해 영상화할 거야.
적합한 영상화 프롬프트를 제시해 줘.
```

> 💡 이미지를 따로 첨부하지 않아도 프롬프트는 나오지만, **실제 만든 이미지를 함께 보여주면** 더 디테일하게 맞춰진 프롬프트를 얻을 수 있다.

제미나이가 카메라 움직임 등이 포함된 영상화 프롬프트를 생성해 준다.

나머지 장면도 동일하게 요청한다:

```
나머지 장면에 대해서도 장면 2에서 장면 3으로, 장면 3에서 장면 4로
계속해서 이어질 수 있도록 하는 영상 프롬프트를 제시해 줘.
```

## 5단계: 영상 제작 (구글 플로우)

### 구글 플로우 접속

구글에서 `Flow` 검색 → 구글 랩스의 구글 플로우 클릭 → 구글 계정 로그인 → `새 프로젝트`

### 영상 생성 설정

프롬프트 입력창 하단 → 이미지/동영상 설정 탭 클릭:

| 항목 | 설정값 |
|------|--------|
| 출력 형식 | 동영상 |
| 프레임 비율 | 16:9 |
| 모델 | 옴니 1.1 플래시 |
| 화질 | 720p |
| 길이 | 10초 |
| 생성 수 | 1개 |

### 이미지 업로드 및 프레임 설정

1. 미드저니에서 다운받은 이미지를 하나의 폴더에 정리해 둔다
2. 이미지를 구글 플로우 화면 위로 **드래그 앤 드롭**으로 올린다
   - 안 되면: 상단 플러스(+) 버튼 → `미디어 추가` → `미디어 업로드` → 파일 선택
   - 또는 좌측 패널의 업로드 버튼 사용
3. 프롬프트 창에 영상화 프롬프트를 붙여넣는다
4. **첫 번째 이미지**를 시작 프레임에, **두 번째 이미지**를 종료 프레임에 끌어서 넣는다
   - 드래그 앤 드롭이 안 되면: 시작 프레임 버튼 클릭 → 이미지 선택 → `프롬프트에 추가`
5. 생성 버튼 클릭

나머지 장면도 동일한 방식으로: 장면 2 → 장면 3, 장면 3 → 장면 4 순서로 시작·종료 프레임을 바꿔가며 제작한다.

### 클립 이어붙이기

만든 영상에서 플러스(+) 버튼 → `클립 추가`에서 다음 영상을 가져와 이어붙일 수 있다.

> 💡 **확장 기능**: 플로우에 "확장" 기능이 있지만, 촬영 시점 기준 옴니 모델에서는 아직 확장이 지원되지 않는다. 향후 반영되면 이미지 없이도 네 개 단위로 매끄럽게 이어붙일 수 있게 될 것이다.

## 6단계: 편집 (프리미어 프로)

### 컷 편집을 하지 않는 이유

> 💡 **꿀팁 — 컷 편집 없이 영상 이어붙이기**: 이 영상에서는 컷 편집을 하나도 하지 않았다. 그냥 영상들을 다 이어붙였다. 이유는 **편집을 간편하게 하기 위함**이다.
>
> 장면이 넘어갈 때 자막이 걸치면 어색해진다. 말은 이어지는데 화면이 먼저 넘어가거나, 화면은 그대로인데 말이 먼저 끝나버린다. 그것을 맞추려면 컷마다 프레임 단위로 잘라주고 붙여줘야 한다.
>
> 그럴 바에는 처음부터 **전환 프롬프트로 각 장면이 자연스럽게 이어지도록** 만들어 놓으면, 뒤에서 거의 손댈 일이 없다. **앞에서 잘 짜두면 뒤에서 고생하지 않는다.**
